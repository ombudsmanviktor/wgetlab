Carregar planilha com URLs

Arraste um arquivo CSV que tenha pelo menos uma coluna com links para imagens, áudios ou vídeos. O arquivo é lido no seu navegador e não é enviado a nenhum servidor.

📂
Arraste o arquivo CSV aqui
ou clique para selecionar · Formato: .csv (UTF-8)
📄

Formatos de célula reconhecidos

  • Uma URL por célula: https://p16.tiktokcdn.com/…/capa.jpeg
  • Várias URLs separadas por |, ;, vírgula ou espaço: https://pbs.twimg.com/media/A?format=jpg | https://video.twimg.com/…/v.mp4
  • JSON com URLs dentro, como a coluna multimedia da Meta Content Library: [{"type":"video","url":"https://…"}]

Células vazias, NA e NULL são ignoradas. A extensão de cada arquivo (jpg, png, mp4, m4a…) é detectada pela URL ou pelo próprio conteúdo baixado.

Abre a janela do seu sistema. Navegue até onde quiser salvar e, se precisar, use o botão Nova pasta da própria janela. O navegador pedirá permissão para gravar nela.

Este navegador não permite gravar direto numa pasta. Os arquivos serão reunidos num ZIP salvo na sua pasta de Downloads (nome do ZIP: ).

Para gravar direto numa pasta escolhida por você, use Chrome, Edge ou Opera no computador. No modo ZIP, tudo fica na memória até o fim: evite milhares de vídeos de uma vez.
